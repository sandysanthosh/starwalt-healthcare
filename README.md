# STARWALT Healthcare

A responsive hospital website showcase for STARWALT.

## Features

- 28 searchable departments and specialties
- Doctor directory with specialty filters
- Appointment request preview
- Patient portal and hospital service demos
- Health packages and FAQs
- Scripted website concierge
- Hospital website proposal brief download

## Run locally

Serve this directory using any static web server, for example `python3 -m http.server 8000`.

## Deploy

GitHub Pages: deploy from `main`, `/ (root)`.

## Demo scope

This is a showcase, not an operating hospital. Doctor profiles and packages are illustrative. No live bookings, medical records, payments, or enquiry transmission are implemented. Proposal briefs download locally. Production integrations require verified hospital details and secure backend services.

Fonts and photos load from Google Fonts and Unsplash.
